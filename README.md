# אלרגן

מאגר וסינון אלרגנים למוצרי מזון ארוזים מראש הנמכרים בישראל.

הרעיון פשוט וההנדסה סביבו לא: לתת לאדם עם אלרגיה לסנן מוצרים לפי מה שהם
מכילים ולפי מה שהם עלולים להכיל, ולסרוק ברקוד מול המדף ולקבל תשובה גם בלי
קליטה. מה שמסבך הוא שהמידע נמצא בשלושה מקומות שונים, אף אחד מהם לא שלם,
והמחיר של טעות בכיוון אחד גבוה בהרבה מהמחיר של טעות בכיוון השני.

## שלושה כללים שמסבירים את רוב הקוד

**1. האפליקציה לעולם לא אומרת שמוצר בטוח.** היא מסתירה מה שידוע כמסוכן
ומתעדת מה שידוע. המילים "בטוח", "נקי" ו"ללא" אינן בשימוש כתיאור של מוצר, אין
ירוק בשום מקום, ו"אין מידע" הוא מצב שלישי מלא ומוצג — לעולם לא "לא מכיל".

**2. מקור שאינו יצרן יכול רק להוסיף אלרגן, לעולם לא לשלול.** חילוץ מתווית או
דיווח משתמש יכולים לסמן סכנה; רק הצהרת יצרן רשמית יכולה לומר שאלרגן נעדר.
האסימטריה מכוונת, כי שתי הטעויות אינן שקולות.
[ADR-0002](docs/adr/0002-extraction-can-add-never-clear.md)

**3. כישלון או שתיקה של מקור לא מחזירים מוצר למצב אין מידע.** מוצר שהיה ידוע
כמכיל בוטנים והמקור הפסיק לדווח עליו הוא כמעט תמיד תקלה אצלנו, לא שינוי במוצר.

## מאיפה מגיע המידע

**הקטלוג** מגיע מקבצי שקיפות המחירים שרשתות השיווק מחויבות בחוק לפרסם. הם
מכילים ברקוד, שם מוצר, שם יצרן וכמות — ולא מכילים אלרגנים.
[ADR-0001](docs/adr/0001-catalog-from-price-transparency-files.md)

**האלרגנים** מגיעים משלושה מקורות שממוזגים יחד: הצהרת היצרן, מיפוי רשימת
הרכיבים, ו-Open Food Facts. דירוג האמינות נקבע לכל שדה בנפרד — היצרן גובר על
השאלה אילו אלרגנים קיימים, אבל לא בהכרח על השאלה באיזו רמה.
[ADR-0004](docs/adr/0004-per-field-source-precedence.md)

הסיבה לכלל האחרון היא ממצא מדף מוצר אמיתי: טאב האלרגנים של במבה קלאסית באתר
אסם-נסטלה מכיל את הטקסט "בוטנים סויה" — רשימה שטוחה, בלי הבחנה. המוצר מכיל
בוטנים ורק עלול להכיל סויה, ואתר היצרן מוחק בדיוק את ההבחנה שכל האפליקציה
בנויה סביבה. ההבחנה משוחזרת בהצלבה מול רשימת הרכיבים.

## הרצה

הפרויקט דורש Python 3.11+ ו-Node 18+. **שניהם אינם מותקנים במכונה שעליה הקוד
נכתב, ולכן הבדיקות והטייפצ'ק טרם רצו אף פעם.** ראו הסעיף האחרון.

```bash
cd pipeline && python -m venv .venv && .venv/Scripts/activate && pip install -e ".[dev]" && pytest
```

```bash
cd app && npm install && npm run typecheck && npm test
```

## מצב הפרויקט

בנוי: מודל התחום המלא, מנוע ההכרעה בין מקורות, פירוק רשימה שטוחה, מיפוי
רכיבים, נרמול עברי לחיפוש, אימות ברקודים, קורא קבצי שקיפות מחירים, מתאם אסם,
מתאם Open Food Facts, בדיקות שפיות, מדיניות מיזוג, בונה תמונת המצב, סכימת
Postgres, וכל מסכי האפליקציה.

לא בנוי: הורדת הקבצים בפועל מהפורטלים, גירוד היצרנים ב-Playwright, שרת ה-API,
אחסון התמונות, ועיבוד צילומי תווית ממשתמשים.

## מה שלא אומת

- **הבדיקות לא רצו.** אין Python ואין Node על מכונת הפיתוח. הקוד נכתב עם
  חבילת בדיקות מלאה, אך אף בדיקה, טייפצ'ק או לינט לא בוצעו בפועל.
- **כיסוי Open Food Facts בישראל לא נמדד.** ה-search API היה חסום בזמן הבדיקה.
- **לא ידוע כמה ממוצרי אסם כוללים בכלל טאב אלרגנים.** נבדק דף מוצר אחד.
- **אישור בחנויות האפליקציות.** אפליקציית אלרגיות עלולה לקבל דרישות ניסוח
  מאפל ומגוגל.
