# הקטלוג נבנה מקבצי שקיפות מחירים, לא מסקרייפינג של אתרי הרשתות

תקנות קידום התחרות בענף המזון (שקיפות מחירים) מחייבות את רשתות השיווק הגדולות לפרסם קבצי XML פומביים עם ברקוד, שם מוצר, שם יצרן וכמות לכל פריט בכל סניף. בחרנו לבנות את כל קטלוג המוצרים מהקבצים האלה במקום לגרד את אתרי הקנייה של הרשתות, כי זה מקור שפרסומו מחויב בחוק, יציב במבנהו, מלא, ואינו חשוף לחסימות או לשינויי עיצוב באתר.

## תוצאות

- הקטלוג שלם ועצמאי לגמרי ממידע האלרגנים. מוצר קיים באפליקציה גם כשאין לנו עליו שום מידע אלרגני.
- כל רשת מממשת את התקנות אחרת (FTP, HTTPS, פורטלים ייעודיים, קידודים שונים) — נדרש מתאם נפרד לכל משפחת מקורות.
- קבצי שקיפות המחירים אינם מכילים אלרגנים כלל. מידע האלרגנים מגיע ממקורות אחרים לחלוטין.
